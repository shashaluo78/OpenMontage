## How to generate

- Use a tool with **image-to-video** where you can upload a reference or start image (Kling, Hailuo, Sora, etc.).
- **Clips 1–3 have three people in them.** Make the start image first (Step 0), then use it as the start frame for Clip 1.
- **For Clips 2 and 3, use the last frame of the clip before as the start frame.** Most tools let you upload a start image, so take a screenshot of the final frame. This keeps faces and the room the same across the cuts.
- **Generate 5-second clips.** I trim them during the edit.
- Generate 2–3 takes of each clip and keep the best. Watch for faces changing and the brush changing shape.
